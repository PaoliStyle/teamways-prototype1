# TeamWays — Demo Features vs Production Features

## Implemented in this prototype (demo)
- Landing page with explanation
- 18-question original questionnaire with Skip / It depends
- Deterministic scoring (min 2 answers per topic; otherwise insufficient)
- Personal provisional profile with tendency text, visual bars, and notes
- Comparison with one fictional demo profile (similarities, differences, hypotheses, questions, draft agreements)
- Conversation coach with six types and pre-written sample guidance (not live AI)
- Six original scenario practice items with supportive feedback
- Editable team working agreement with local save and print-friendly view
- English / Spanish interface toggle
- Clear all browser-local data
- Responsive, accessible-enough layout (labels, contrast, keyboard-friendly buttons)

## Described for a future production version (not implemented)
- Authentication and organisation-level access controls
- Database storage and versioned questionnaire results
- Explicit profile-sharing controls (only with consent)
- Server-side AI calls for coaching (no secrets in client)
- Export, deletion, retention settings, and audit logging
- Strict separation between organisations’ data
- Additional languages, accessibility audit, user research validation

Do not claim production features exist in the current prototype.
